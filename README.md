# On-Demand Workforce Management System

A full-stack web application that connects customers with skilled workers for on-demand services. The system simplifies worker discovery, service booking, workforce management, and booking tracking through a centralized platform.

### Key Features

* User registration and secure login
* Worker registration and profile management
* Skill-based worker discovery
* On-demand service booking
* Booking and request management
* Worker availability tracking
* Admin management and monitoring
* MySQL database integration

### Tech Stack

**Frontend:** HTML, CSS, JavaScript
**Backend:** Python, Flask
**Database:** MySQL

This project focuses on building an efficient, scalable, and user-friendly platform for managing on-demand workforce services.
